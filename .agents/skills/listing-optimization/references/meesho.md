# Meesho Listing Optimization Reference

Meesho support is an extension point in the initial release.

When Meesho is selected:

1. Ask for the Meesho listing fields and available search/performance data one item at a time.
2. Do not assume Amazon field names, limits, or ranking behavior.
3. Collect the first/main image and other product images.
4. Wait until all marketplace-specific inputs are received before generating.
5. Apply the common Listing Optimization rules: factual accuracy, relevance, image verification, no premature output, and exclusion review.

Add verified Meesho marketplace rules here as they are established.
